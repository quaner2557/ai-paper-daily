# 🖥️ 相关论文查找器 - Web 交互界面

## 🚀 快速启动

### 1. 启动 Web 服务

```bash
cd /Users/nuannuan/.openclaw/workspace/ai-paper-daily
python3 find_related_web.py
```

### 2. 访问页面

打开浏览器访问：**http://localhost:5000**

---

## 📋 功能特性

### 输入参数

| 参数 | 说明 | 必填 | 默认值 |
|------|------|------|--------|
| 🔑 API 密钥 | 阿里云百炼 API Key | ✅ | - |
| 📝 研究摘要 | 你的研究内容描述 | ✅ | - |
| 🏷️ 关键词 | 用于快速筛选（逗号分隔） | ❌ | - |
| 📊 粗排截断量 | 初筛候选论文数量 | ❌ | 200 |
| 🎯 精排返回量 | 最终返回的论文数 | ❌ | 10 |

### 查找流程

```
用户摘要 → 关键词筛选 (可选) → Flash 初筛 → Plus 精排 → 返回结果
                              (200 篇)      (Top10)
```

1. **关键词预筛选**（可选）：根据关键词快速过滤论文库
2. **Flash 初筛**：使用 `qwen3.5-flash` 对所有论文快速打分，选出 Top 200
3. **Plus 精排**：使用 `qwen3.5-plus` 对候选论文详细评估，返回 Top 10

## ⚙️ 配置说明

### API 密钥获取

1. 访问 [阿里云百炼](https://bailian.console.aliyun.com/)
2. 创建 API Key
3. 确保开通以下模型：
   - `qwen3.5-flash`（粗排）
   - `qwen3.5-plus`（精排）

### 参数建议

| 场景 | 粗排截断量 | 精排返回量 | 预计耗时 |
|------|-----------|-----------|---------|
| 快速测试 | 100 | 5 | ~2 分钟 |
| 标准查找 | 200 | 10 | ~5 分钟 |
| 深度挖掘 | 500 | 20 | ~10 分钟 |

## 🛠️ 技术栈

- **前端**: 原生 HTML + CSS + JavaScript
- **后端**: Python `http.server`
- **LLM**: 阿里云百炼 Qwen 系列
- **数据源**: `output/*.json` 精排论文库

## ⚠️ 注意事项

1. **API 费用**：每次查找会调用 LLM API，产生费用
   - Flash 初筛：约 200 次调用
   - Plus 精排：约 200 次调用
   - 建议先用小参数测试

2. **耗时**：
   - 首次启动需要加载论文库（~5 秒）
   - 查找耗时取决于参数设置（2-10 分钟）

3. **论文库更新**：
   - 自动从 `output/*.json` 加载
   - 需要定期运行 `main.py` 更新数据

## 🔧 故障排查

### 问题 1: 找不到论文

**原因**: `output/` 目录为空或没有数据

**解决**: 先运行 `python3 main.py` 生成论文数据

### 问题 2: API 调用失败

**原因**: API Key 无效或余额不足

**解决**: 检查阿里云百炼控制台

### 问题 3: 端口被占用

**原因**: 5000 端口已被使用

**解决**: 修改 `find_related_web.py` 中的端口号
