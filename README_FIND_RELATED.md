# 🔍 相关论文查找工具

根据你提供的文章摘要，从所有精选论文中找到相同方向的论文并打分。

---

## 📖 使用方法

### 方式 1：交互式运行（推荐）

```bash
cd /Users/nuannuan/.openclaw/workspace/ai-paper-daily
python3 find_related.py
```

然后按提示输入你的文章摘要。

---

### 方式 2：命令行参数

```bash
python3 find_related.py --abstract "你的文章摘要" --top-k 10
```

**参数说明：**
- `--abstract` 或 `-a`: 你的文章摘要（必填）
- `--top-k` 或 `-k`: 返回最相关的 K 篇论文（默认 10）
- `--output` 或 `-o`: 输出文件名（默认 related_papers.json）

**示例：**
```bash
python3 find_related.py -a "我们提出了一种新的 Transformer 架构用于文本分类..." -k 15
```

---

### 方式 3：从文件读取摘要

```bash
python3 find_related.py --abstract-file my_abstract.txt
```

## 🎯 评分标准

LLM 从以下维度评估相关性（0-10 分）：

1. **研究任务/问题** - 是否解决相似的问题
2. **方法/技术** - 是否使用类似的技术
3. **应用领域** - 是否在同一领域
4. **可引用性** - 是否可以互相引用参考

**相关性等级：**
- 🔥 **高度相关** (8-10 分) - 强烈推荐
- ⭐ **中等相关** (6-8 分) - 值得参考
- 📌 **低度相关** (4-6 分) - 可能有用
- ⚪ **微弱相关** (0-4 分) - 关联较弱
